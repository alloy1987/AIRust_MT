## ✨ 機能

- **見たまま編集（WYSIWYG）**：MarkText のエディタコア `@muyajs/core` をベースに、入力しながら即座にレンダリング。分割プレビューは不要
- **豊富なブロック要素**：見出し、リスト、テーブル、コードブロック（シンタックスハイライト）、数式（KaTeX）、図表（Mermaid / flowchart / PlantUML / Vega）、HTML ブロック、Front Matter など
- **マルチタブ**：複数のドキュメントを同時に編集可能。未保存の変更を通知
- **ファイルサイドバー**：フォルダをワークスペースとして開き、ファイルツリーの閲覧・新規作成・名前変更・削除が可能
- **プレーンテキスト編集**：Markdown に加え、一般的なプレーンテキストファイルをそのまま（解析なしで）開いて編集できます：データ・設定ファイル（.json / .yaml / .yml / .xml / .toml / .ini / .csv / .env）、ドキュメント・ウェブページ（.txt / .html / .htm / .css / .rtf）、ソースコード（.py / .js / .ts / .java / .c / .cpp / .go / .rs）。現在のファイルの拡張子はステータスバーに表示されます
- **スマートなテキスト検出**：ファイルを開けるかどうかは拡張子ではなく内容で判断されます——未知の拡張子のテキストファイルは問題なく開けますが、バイナリファイルは検出されて警告付きで拒否されます
- **アウトラインパネル**：見出し階層による素早いナビゲーション
- **検索 / 置換**：正規表現、大文字小文字の区別、単語単位のマッチングに対応
- **画像サポート**：画像の貼り付け・ドラッグで自動的にドキュメントのディレクトリへ保存して挿入
- **ファイル監視**：ドキュメントがディスク上で外部から変更された場合に自動通知
- **エンコーディング検出**：`encoding_rs` + `chardetng` により非 UTF-8 ファイルのエンコーディングを自動検出・変換
- **大容量ファイル処理**：超大ファイルは読み取り専用のプレビューで開き、フリーズを回避
- **12 種類のテーマ**：ブライトホワイト、ダークブラック、インディゴ、エメラルドグリーン、サンセットオレンジ、ディープシーブルー、ローズピンク、ドーンゴールド、ミント、スカイブルー、ピーチピンク、ラベンダー
- **7 言語の UI**：中文、English、日本語、Русский、한국어、Español、Français
- **UI ズーム**：Ctrl + ホイール / メニューでズーム。高 DPI 画面に対応
- **シングルインスタンス**：二重起動時は既存ウィンドウにフォーカスしてファイルを開く
- **Windows NSIS インストーラ**：多言語セットアップウィザード。ファイルのドラッグ＆ドロップによる起動に対応

## 📦 インストール

### Windows（インストーラ .exe）

- インストール前に、**Microsoft Edge WebView2 ランタイム**（web2view、略称 WebView2）がインストールされていることを確認してください；
- インストール中、インストーラは WebView2 がインストール済みか自動的に検出します：
  - インストール済みの場合は、そのままインストールを続行します；
  - 未インストールの場合は、インストーラが案内を表示し、自動的にオンラインで WebView2 をダウンロード・インストールします；
- 事前に手動で WebView2 をダウンロード・インストールすることもできます。公式ダウンロードページ：<https://developer.microsoft.com/microsoft-edge/webview2/>

### macOS と Linux

> macOS と Linux 向けのインストーラはまだ公開されていませんが、ソースコードから自分でビルドできます。詳細は後述の[ビルド](#ビルド)を参照してください。

## 🔐 プライバシーについて

> 本アプリは全体として**ローカルでオフライン動作**しますが、以下の図表機能は例外で、レンダリング時にインターネット接続が必要です：
>
> - **PlantUML 図**：図のソースコードは公開サーバー `plantuml.com` に送信され、レンダリングされた画像が返されます。図の内容はマシンの外部へ送信されます；
> - **シーケンス図（sequence）**：レンダリング時に webfontloader 経由で Google Fonts からフォントを読み込みます。
>
> その他の機能（編集、保存、画像、エンコーディング検出など）は一切ネットワークリクエストを行いません。ドキュメントの内容が機密情報を含む場合は、上記 2 種類の図表の使用を避けてください。

## 🛠️ ビルド

前提条件：[Rust](https://www.rust-lang.org/)、[Node.js](https://nodejs.org/) ≥ 20、[pnpm](https://pnpmjs.com/)、および [Tauri 2 のシステム依存関係](https://tauri.app/start/prerequisites/)。

各プラットフォームの追加要件：

- **Windows**：[Microsoft Edge WebView2 ランタイム](https://developer.microsoft.com/microsoft-edge/webview2/)（通常はシステムにインストール済み）；
- **Linux**：[Tauri 公式の前提条件](https://tauri.app/start/prerequisites/)に記載されているシステムパッケージ（例：`webkit2gtk-4.1`、`libappindicator3`、`librsvg2-dev`）をインストール；
- **macOS**：[Xcode Command Line Tools](https://developer.apple.com/xcode/)（`xcode-select --install`）。

```bash
# 依存関係のインストール
pnpm install

# 開発モード（ホットリロード）
pnpm tauri dev

# リリース版インストーラのビルド
pnpm tauri build
```

各プラットフォームの成果物：

- Windows：`src-tauri/target/release/bundle/nsis/*.exe`
- macOS：`src-tauri/target/release/bundle/macos/*.app` と `dmg/*.dmg`
- Linux：`src-tauri/target/release/bundle/deb/*.deb`、`rpm/*.rpm`、`appimage/*.AppImage`

### 特別な感謝

ここで、**Mozilla と Rust Foundation（Rust 財団）に心からの感謝**を捧げたいと思います。彼らの努力により、私たちは非常に優れたプログラミング言語 Rust を得ることができました！
AI 支援プログラミングの潮流の中で、Rust が大きな可能性を秘めた開発言語となったのは、主に低レベルのシステム言語として備える 4 つの核心的な利点によるものです：

1. **究極の実行効率と低レベル制御力**
   ハードウェアに近いシステムプログラミング言語として、Rust は従来言語のガベージコレクション（GC）機構を廃し、ゼロコスト抽象化を提供します。これにより、開発効率を保ちながら C/C++ に匹敵する極めて高い実行性能とメモリ制御力を実現し、AI 時代の高性能コンピューティングと高並行処理のニーズに完璧に適合します。

2. **厳格なメモリ安全性と信頼性の保証**
   Rust はその厳格な構文と独自の所有権（Ownership）・借用チェック（Borrow Checker）機構で知られています。コンパイル段階でヌルポインタやデータ競合などのメモリ安全上の問題を正確に阻止できます。この「コンパイル時に安全」という特性は、AI が生成したコードに強力な品質のセーフティネットを提供し、実行時クラッシュのリスクを大幅に低減します。

3. **強力な型システムによる AI への「意味的制約」**
   Rust は高度に標準化された厳格な強力な型システムを持っています。AI プログラミングの文脈では、この型システムはコードの規範であるだけでなく、AI の「ナビゲーター」でもあります。明確な型定義は AI がビジネスロジックとデータフローをより正確に理解する助けとなり、AI の「幻覚」や論理の欠陥による無効なコードを効果的に削減し、AI が生成したコードを本質的により堅牢なものにします。

4. **公式コンパイラという「厳格な品質検査官」**
   Rust は公式に成熟した極めて厳格なコンパイラツールチェーンを提供しています。AI 支援開発のワークフローでは、AI がコードの初稿を迅速に生成し、Rust コンパイラが最初の厳格な品質ゲートとして機能します。AI が生成したコードがコンパイルを通過できた時点で、メモリ安全性と型の一致における致命的なエラーの大半が排除されたことを意味します。この「AI が生産を担当し、コンパイラが品質検査を担当する」という補完モデルは、産業グレードのコードの納品品質を大きく向上させます。
   **まとめると、AI 支援プログラミングの時代において、開発言語として Rust を選択することは極めて高い戦略的価値を持ちます。より多くの有能な人々が Rust プログラミングの大軍に加わり、Rust エコシステムがますます豊かになることを願っています。**

## 🤖 開発方式

本プロジェクトは **AI 支援プログラミング（vibe coding）** の実践です：

- **コーディングモデル**：[DeepSeek V4 Flash](https://www.deepseek.com/) / [Qwen 3.8](https://www.qianwenai.com/)
- **画像モデル**：[Qwen 3.8](https://www.qianwenai.com/)
- **プログラミングエージェント**：[opencode](https://opencode.ai)（インタラクティブ AI プログラミング CLI）、[Qwencode](https://www.qianwenai.com)
- **人間の役割**：要件定義、アーキテクチャ決定、コードレビュー、受け入れテスト

プロジェクトは MarkText を青写真とし、その Electron シェルを Rust + Tauri 2 に置き換え、エディタコアは MarkText の muya をそのまま継承・適応させています。
