## ✨ Возможности

- **Редактирование WYSIWYG**: на основе ядра редактора MarkText `@muyajs/core` — мгновенный рендеринг при вводе, без раздельного предпросмотра
- **Богатые блочные элементы**: заголовки, списки, таблицы, блоки кода (подсветка синтаксиса), математические формулы (KaTeX), диаграммы (Mermaid / flowchart / PlantUML / Vega), HTML-блоки, Front Matter и др.
- **Несколько вкладок**: одновременное редактирование нескольких документов с напоминанием о несохранённых изменениях
- **Боковая панель файлов**: открытие папки как рабочей области, просмотр дерева файлов, создание, переименование, удаление
- **Правка обычного текста**: помимо Markdown, открывает и редактирует распространённые текстовые файлы как обычный текст (без разбора): данные и конфигурация (.json / .yaml / .yml / .xml / .toml / .ini / .csv / .env), документы и веб-страницы (.txt / .html / .htm / .css / .rtf), а также исходный код (.py / .js / .ts / .java / .c / .cpp / .go / .rs); расширение текущего файла отображается в строке состояния
- **Умное определение текста**: возможность открытия файла определяется его содержимым, а не расширением — текстовые файлы с неизвестными расширениями открываются нормально, а бинарные файлы распознаются и отклоняются с предупреждением
- **Панель структуры**: быстрая навигация по уровням заголовков
- **Поиск / замена**: поддержка регулярных выражений, учёта регистра и поиска целых слов
- **Поддержка изображений**: вставка и перетаскивание изображений с автоматическим сохранением в каталог документа и вставкой
- **Наблюдение за файлами**: автоматическое уведомление при внешнем изменении документа на диске
- **Определение кодировки**: автоматическое определение и преобразование кодировок не-UTF-8 файлов на базе `encoding_rs` + `chardetng`
- **Работа с большими файлами**: очень большие файлы открываются в режиме предпросмотра только для чтения, чтобы избежать зависаний
- **12 тем оформления**: ярко-белая, тёмно-чёрная, индиго, изумрудная, закатно-оранжевая, глубоководная синяя, розовая, рассветное золото, мятная, небесно-голубая, персиковая, лавандовая
- **7 языков интерфейса**: 中文, English, 日本語, Русский, 한국어, Español, Français
- **Масштабирование интерфейса**: Ctrl + колесо мыши / меню, адаптация для экранов с высоким DPI
- **Один экземпляр**: при повторном запуске фокус на существующем окне и открытие файла
- **Установщик Windows NSIS**: многоязычный мастер установки, поддержка открытия файлов перетаскиванием

## 📦 Установка

### Windows (установщик .exe)

- Перед установкой убедитесь, что в системе установлена **среда выполнения Microsoft Edge WebView2** (web2view, сокращённо WebView2);
- В процессе установки программа автоматически проверит, установлен ли WebView2:
  - если установлен — установка продолжится напрямую;
  - если нет — установщик покажет подсказку и автоматически загрузит и установит WebView2 из сети;
- Вы также можете заранее вручную загрузить и установить WebView2. Официальная страница загрузки: <https://developer.microsoft.com/microsoft-edge/webview2/>

### macOS и Linux

> Установочные пакеты для macOS и Linux пока не опубликованы, но вы можете собрать приложение из исходного кода самостоятельно. См. раздел [Сборка](#сборка) ниже.

## 🔐 Конфиденциальность

> Приложение в целом работает **локально и офлайн**, за исключением следующих функций диаграмм, которым при рендеринге требуется подключение к сети:
>
> - **Диаграммы PlantUML**: исходный код диаграммы отправляется на публичный сервер `plantuml.com`, который возвращает отрендеренное изображение; содержимое диаграммы покидает ваш компьютер;
> - **Диаграммы последовательности (sequence)**: при рендеринге шрифты загружаются из Google Fonts через webfontloader.
>
> Все остальные функции (редактирование, сохранение, изображения, определение кодировки и т. д.) не выполняют никаких сетевых запросов. Если содержимое документа конфиденциально, избегайте использования указанных двух типов диаграмм.

## 🛠️ Сборка

Требования: [Rust](https://www.rust-lang.org/), [Node.js](https://nodejs.org/) ≥ 20, [pnpm](https://pnpmjs.com/), а также [системные зависимости Tauri 2](https://tauri.app/start/prerequisites/).

Дополнительные требования по платформам:

- **Windows**: [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (обычно уже установлен);
- **Linux**: установите системные пакеты из [официальных требований Tauri](https://tauri.app/start/prerequisites/), например `webkit2gtk-4.1`, `libappindicator3`, `librsvg2-dev`;
- **macOS**: [Xcode Command Line Tools](https://developer.apple.com/xcode/) (`xcode-select --install`).

```bash
# Установка зависимостей
pnpm install

# Режим разработки (горячая перезагрузка)
pnpm tauri dev

# Сборка релизного установщика
pnpm tauri build
```

Результаты сборки по платформам:

- Windows: `src-tauri/target/release/bundle/nsis/*.exe`
- macOS: `src-tauri/target/release/bundle/macos/*.app` и `dmg/*.dmg`
- Linux: `src-tauri/target/release/bundle/deb/*.deb`, `rpm/*.rpm`, `appimage/*.AppImage`

### Особая благодарность

Здесь я хочу **особо поблагодарить** Mozilla и Rust Foundation (фонд Rust) — благодаря их усилиям мы получили превосходный язык программирования Rust!
В волне программирования с помощью ИИ Rust стал чрезвычайно перспективным языком разработки в первую очередь благодаря четырём ключевым преимуществам как низкоуровневого системного языка:

1. **Предельная эффективность выполнения и низкоуровневый контроль**
   Как системный язык программирования, близкий к аппаратному уровню, Rust отказался от традиционного механизма сборки мусора (GC) и предлагает абстракции с нулевой стоимостью. Это позволяет при сохранении эффективности разработки достигать производительности выполнения и контроля памяти, сопоставимых с C/C++, что идеально отвечает потребностям эпохи ИИ в высокопроизводительных вычислениях и высокой степени параллелизма.

2. **Строгая безопасность памяти и гарантии надёжности**
   Rust известен своей строгой грамматикой и уникальными механизмами владения (Ownership) и проверки заимствований (Borrow Checker). Он способен точно перехватывать на этапе компиляции такие угрозы безопасности памяти, как нулевые указатели и гонки данных. Свойство «безопасность уже на этапе компиляции» обеспечивает мощную страховку качества для кода, сгенерированного ИИ, и значительно снижает риск сбоев во время выполнения.

3. **Строгая система типов как «семантическое ограничение» для ИИ**
   Rust обладает высокостандартизированной и строгой системой типов. В контексте программирования с помощью ИИ эта система типов — не только спецификация кода, но и «навигатор» для ИИ. Чёткие определения типов помогают ИИ точнее понимать бизнес-логику и потоки данных, эффективно сокращая нерабочий код, порождаемый «галлюцинациями» или логическими ошибками ИИ, что делает сгенерированный ИИ код по своей природе более надёжным.

4. **Официальный компилятор как «строгий контролёр качества»**
   Rust официально предоставляет зрелую и чрезвычайно строгую цепочку инструментов компилятора. В рабочем процессе разработки с помощью ИИ ИИ отвечает за быструю генерацию черновиков кода, а компилятор Rust выступает первым строгим барьером контроля качества. Если сгенерированный ИИ код компилируется, это означает, что подавляющее большинство фатальных ошибок в безопасности памяти и соответствии типов уже исключено. Такая дополняющая модель «ИИ производит — компилятор проверяет» значительно повышает качество поставки кода промышленного уровня.
   **Итак, в эпоху программирования с помощью ИИ выбор Rust в качестве языка разработки имеет чрезвычайно высокую стратегическую ценность. Я также надеюсь увидеть, как всё больше способных людей присоединяются к рядам Rust-программистов, делая экосистему Rust всё богаче.**
